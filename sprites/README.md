# sprites/ 像素精灵图交付目录

美术把导出的 PNG 直接放进本目录即可，**文件名必须严格符合规范**，游戏启动时自动识别；缺动作/缺整只都不会报错，自动回退职业像素模板。

## 一、硬性规格（不符合会被自检拦下）

| 项 | 规格 |
|---|---|
| 单帧尺寸 | **48 / 64 / 96 px 三档均可**（必须正方帧；渲染按比例缩放，同一批尽量统一；96 档为 v3 极致打磨档，横版战斗内统一显示 116×116） |
| 排列 | 横向序列帧（Sprite Sheet，从左到右），一张图 = 一个动作 |
| 背景 | 透明 PNG（PNG-32），不要底色块 |
| 朝向 | **面向右**；敌方由程序自动镜像（scaleX(-1)），不用画反方向 |
| 地面线 | 脚底踩在画布底部第 2~4 行（48 画布 y=46；64 画布 y=62；96 画布 y=92），否则战斗里会"漂浮" |
| 像素 | 纯硬边、无抗锯齿、无模糊缩放；导出 100% 原尺寸 |
| 整张宽 | 帧边长 × 帧数。64 档：idle/attack/cast=256×64、hurt=128×64、die=192×64；96 档 v3：idle/attack/skill=576×96、hurt=288×96 |

## 二、动作 / 帧数 / 播放速度（与程序 SPRITES 配置一致，帧数不能改）

| 动作 | 帧数 | fps | 优先级 | 动作要点 |
|---|---|---|---|---|
| idle 待机 | 4 | 2 | P0 | 呼吸：正常→下沉1px半闭眼→回位→手臂微摆，首尾衔接可循环 |
| attack 攻击 | 4 | 12 | P0 | 蓄力后仰→前冲3px→武器最大伸展→回位，一次性播完回 idle |
| hurt 受击 | 2 | 8 | P0 | 后仰+偏红→回位，一次性 |
| cast 施法 | 4 | 12 | P1 | 双手举→聚气光点→前推→回位（法术职业用，物理职业可复用攻击节奏） |
| skill 斗气技 | 6 | 8 | P1 | **v3 档专用**：聚气→蓄力光球→爆发环→前冲拖光轨→命中爆炸→回位；非普攻物理技能触发，缺省时自动回退 attack |
| die 死亡 | 3 | 6 | P1 | 倒地→变淡→消散轮廓，播完停留最后一帧 |

**v3 单只极致档（pet_001 寅将军，96×96，21 帧）**：idle6@2 / attack6@10（前冲 16px、枪头顶到画布边）/ skill6@8（金色斗气"悍摧城"）/ hurt3@12（**闪白**非闪红，轮廓不染白）；cast 复用 skill sheet，die 沿用 64 档。详见 `像素精灵图v3指令_单只极致打磨.md`，生成器 `generate_sprite_v3.py`。

**最低交付：idle 一张即可进游戏看静态效果；P0 三件套（idle/attack/hurt）算该宠动作完整。**

## 三、命名硬规范

`{petId}_{动作}.png`，全部小写，例如：

```
pet_001_idle.png  pet_001_attack.png  pet_001_hurt.png  pet_001_cast.png  pet_001_die.png
```

petId 与动作名都不允许自造；交付后运行 `node _check_sprites.js` 自检（命名/尺寸/帧数/缺件一次查清）。

## 五、Aseprite 导出步骤

File → Export Sprite Sheet → Sheet Type: **Horizontal**（横向）→ Layout 每行动画帧数 →
Constraints 不勾选缩放 → Output 选 PNG、透明背景 → 文件名按第三节命名 → 存入本目录。

## 六、交付后程序侧操作（美术不用做，仅备查）

1. `node _check_sprites.js`：自检全部 PNG 的命名/尺寸/帧数/完整度；
2. 直接双击 `index.html` 即可看到效果（外链模式，图在本目录）；
3. 若要封成"不依赖本目录的纯单文件"，运行 `node _inline_sprites.js` 生成 `index-inline.html`（PNG 内联为 data URI）。
